# TaskBoard

Дошка завдань: навчальний наскрізний проєкт з дисципліни «Технології створення веб-застосунків».

## Автор
- **Ім'я:** Софія Казанівська
- **Група:** КН-3/1

## Про проєкт
TaskBoard дозволяє створювати завдання, міняти їм статуси й відстежувати виконання. Проєкт розвивається поетапно протягом курсу.

## Технології
| Шар | Технології |
| --- | --- |
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, Flask *(буде додано)* |
| База даних | SQLAlchemy, PostgreSQL *(буде додано)* |
| Розгортання | Docker *(буде додано)* |
